# Payday Quest

เกมฝึกจัดการเงินเดือนบนมือถือ เดินในเมือง จ่ายบิล รับงานเสริม แบ่งเงินไปเก็บและลงทุน · 1 เดือนในเกม = 3 นาที

**เล่นได้ที่:** https://yothinint.github.io/payday-quest/

> เกมจำลองเพื่อการเรียนรู้และความสนุก ไม่ใช่คำแนะนำการลงทุน ชื่อและตัวเลขทั้งหมดเป็นการสมมติ

## ไฟล์
- `payday-quest.html` ต้นฉบับเกม → `./build.sh` สร้าง `index.html` (หน้าที่เปิดบนเว็บ)
- `img/` ภาพในเกม (WebP) สร้างจากภาพต้นฉบับด้วย `python3 tools/make_img.py`
